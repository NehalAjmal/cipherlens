# models_cache/

Downloaded/cached model weights for CipherLens.

- Reference backbone (ResNet-18 or MobileNetV3) — downloaded once via `scripts/download_reference_backbone.py`.
- Demo trojaned models — built during red-team phases.

**This directory is gitignored.** Contents are regenerated per machine via setup scripts.

See `docs/HUMAN_TASKS.md` §3 for download instructions.
